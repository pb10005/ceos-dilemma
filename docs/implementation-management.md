# 実装管理ドキュメント（PM向け）

## 1. ドキュメント目的
本ドキュメントは `plan.md` を実行可能なプロジェクト運営計画に変換し、Webゲーム開発（MVP）における進行管理・品質管理・リスク管理を標準化するための管理文書である。

- 対象プロダクト: **CEO's Dilemma（MVP）**
- 対象期間: Phase 1〜Phase 8
- 開発体制: AIエージェント実装 + 人間レビュー

---

## 2. スコープ管理

### MVPスコープ（実装対象）
- ターン制進行（1ターン=1四半期）
- 会社ステータス管理
- PL / BS / CF の簡易計算
- 意思決定（広告・生産・採用・R&D・借入・返済・エクイティ）
- イベントカード
- 倒産判定
- チュートリアル（12四半期）
- 結果レポート（学習ポイント含む）

### 非スコープ（MVPでは未実装）
- 複雑なM&A
- 海外展開
- 詳細税務
- 多国籍サプライチェーン
- IPO詳細シミュレーション

---

## 3. フェーズ別実行計画（WBS）

| Phase | 目的 | 主タスク | 成果物 | 完了判定 |
|---|---|---|---|---|
| 1 | 初期化 | Next.js + TypeScript + Tailwind 構築 | 起動可能アプリ骨格 | `npm run dev`で画面表示 |
| 2 | データ定義 | 型定義・初期JSON作成 | `types/*` `data/*` | 型エラーなし |
| 3 | 財務計算 | 純粋関数化 + 単体テスト | `lib/finance.ts` + tests | 主要計算テスト合格 |
| 4 | ターン処理 | `processTurn` 実装 | `lib/gameEngine.ts` | 1ターン進行/倒産判定可 |
| 5 | UI実装 | Dashboard/Decision/Statements等 | `components/*` | 入力→次ターン反映 |
| 6 | 学習体験 | 用語説明・失敗理由・学習ログ | glossary連携UI | 学習ポイント表示 |
| 7 | チュートリアル | 12Qガイドシナリオ | `data/scenarios.json`等 | 12ターン完走 |
| 8 | 品質改善 | レスポンシブ/フォーマット/E2E | Playwrightテスト | 主要導線E2E合格 |

---

## 4. 依存関係と順序制約

1. **Phase 1完了前にPhase 2以降へ進まない**（土台欠如防止）
2. **Phase 2完了前にPhase 3・4へ進まない**（型の先行確定）
3. **Phase 3完了前にPhase 5へ進まない**（財務ロジックの正当性担保）
4. **Phase 4完了前にPhase 7へ進まない**（シナリオ進行ロジック依存）
5. **Phase 8は全フェーズ成果物を入力に実施**

---

## 5. 品質ゲート（Definition of Done）

各Phase完了時に以下ゲートを必須とする。

- 型チェック通過
- Lint通過
- 単体テスト通過（該当Phase）
- 変更点がREADME/管理文書に反映
- 仕様差分（planとの差分）をPRに明記

推奨チェックコマンド:

```bash
npm run typecheck
npm run lint
npm run test
npm run test:e2e
```

---

## 6. リスク管理

| リスク | 発生要因 | 影響 | 対応策 |
|---|---|---|---|
| 財務計算の不整合 | ロジック複雑化 | 学習価値毀損 | 先に純粋関数+テスト固定 |
| UI先行による手戻り | 仕様未固定で画面実装 | 工数増 | Phase順序の厳守 |
| バランス崩壊 | 定数ハードコード | 難易度破綻 | 係数はJSON外出し |
| チュートリアル離脱 | 説明不足 | 継続率低下 | 序盤3ターンガイド強化 |
| E2E不安定 | 非決定的イベント | CI失敗 | テスト時シード固定 |

---

## 7. KPI（開発進行）

- フェーズ達成率（完了Phase/全8Phase）
- バグ再発率（同一原因の再オープン件数）
- テスト安定率（CI連続成功回数）
- 学習機能実装率（用語・学習ポイント要件達成率）

---

## 8. レビュー運用

- 実装PRは原則「1フェーズ=1PR」
- PRテンプレート必須項目
  - 変更概要
  - plan.md対応箇所
  - 完了条件チェック
  - テスト結果
  - 未完項目/次フェーズ引き継ぎ
